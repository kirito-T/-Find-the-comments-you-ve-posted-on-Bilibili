# -Find-the-comments-you-ve-posted-on-Bilibili
这是我的第一个作品。在哔哩哔哩里如果要找自己发过的评论，除了别人回你，或者点赞你的评论之外，自己压根就找不到。这个插件可以帮你找到你发表过的评论（要是太久远会找不到，这点我很抱歉），也可以用在你的deepseek上。使用方法：直接丢给deep seek开完全权限，推理等级MAX让她自己帮你安上去就好了。我很爱我的deepseek，所以我做出了这个，感谢你的使用。Find your own Bilibili comments. Bilibili hides them — this finds them.
